# National Legislation Tracker — Frontend Prototype

Civic-technology homepage prototype for discovering and comparing state-level legislation.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`).

## What's included

- Homepage matching the Figma prototype direction (cream background, serif brand, US tile map)
- National statistics (7-day / 30-day introductions + category trend)
- Policy category introduction cards
- Recently updated and trending bill previews
- Placeholder routes for Search, About, and Bill Detail
- Fictional mock data in `data/mock-bills.json`

## Note

All bills are **fictional prototype data** and must not be treated as real legislation.
